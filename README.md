
# Trap the Intruder
### A 2D Network Security Strategy Game Using Graph Algorithms

**Trap the Intruder** is a 2D strategy game based on graph theory and network security concepts. In this game, an attacker attempts to reach a target server through a network, while a defender tries to stop the attacker by placing different types of traps and protecting important network connections.

The main purpose of this project is to demonstrate how graph algorithms can be applied to a practical and interactive scenario.

---

## Project Overview

The game represents a computer network as a weighted graph, where:

- **Nodes (Vertices):** Represent servers or network devices.
- **Edges:** Represent connections between network devices.
- **Weights:** Represent the cost of traveling through a connection.
- **Attacker:** Attempts to find the best route to the target server.
- **Defender:** Uses network analysis to identify critical connections and prevent the attack.

The project focuses on implementing graph algorithms in C and presenting their operations through a 2D graphical interface.

## Algorithms Used

### 1. Dijkstra's Algorithm

Dijkstra's algorithm is used by the attacker to find the minimum-cost path from the entry point to the target server.

It calculates the shortest path based on the weights assigned to network connections.

**Purpose:**
- Find the minimum-cost route.
- Analyze different possible paths.
- Demonstrate weighted graph traversal.

**Time Complexity:**
- Array-based implementation: O(V²)
- Priority queue implementation: O((V + E) log V)

### 2. Ford-Fulkerson Algorithm

Ford-Fulkerson is planned for the defender's network analysis.

It calculates the maximum flow through a network using edge capacities.

**Purpose:**
- Analyze network capacity.
- Identify important network connections.
- Support minimum-cut analysis.

**Time Complexity:**
- O(E × F) for the basic integer-capacity implementation, where F is the maximum flow value.

### 3. Minimum Cut

The minimum-cut concept is used to identify a minimum-capacity set of connections whose removal separates the attacker from the target.

This will help demonstrate how network vulnerabilities can be analyzed using graph theory.

## Performance Analysis

One of the objectives of this project is to analyze the performance of graph algorithms.

We plan to test the algorithms using networks of different sizes and compare:

- Execution time.
- Memory usage.
- Number of vertices.
- Number of edges.
- Algorithmic complexity.

This will help us understand how the algorithms perform as the network grows.

## How the Game Will Work

1. The game generates a network containing multiple connected nodes.
2. The attacker starts from a predefined entry point.
3. Dijkstra's algorithm calculates the minimum-cost route to the target.
4. The defender places traps to interfere with the attacker's route.
5. The defender uses maximum-flow and minimum-cut analysis to identify critical connections.
6. The game evaluates whether the attacker reaches the target or is successfully stopped.
